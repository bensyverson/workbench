## The result in one paragraph

What drives them now is almost entirely the rules Ben parked: the narrower Runtime Subset (strings, arrays, `**`, bitwise), names a local may not take, a lambda written in place, a handle passed whole, plus the uncalled helper's untyped parameter. The sheet still requires all of them, so a diligent agent still writes a parser.

## New findings

- **Diagnostic order.** C and D report that their builder-stage checks always run before the kit's lambda checks, so they cannot follow the sheet's "which number" order against `L…` codes. F asks for a `priority` on `ctx.error`.
- **Root-check location.** A, B and D: a root `check` cannot point at a helper or constant, so its errors land on the export line.
- **Messages from another lambda's view.** E and F: `rng()` in a force gives B013 ("a parameter of another lambda"), and `p.kill()` in spawn gives a bare L004. The sheet wants a message that names the mistake. Both ask for per-slot `rejected` messages on effects and free names.
- **Duplicate diagnostics remain.**
  - Fixed since this run (issue `Uv2uas`): `p.n || 2` gave three L003s.
  - Still open:
    - a helper given two types gives L003 and L014 (B, C);
    - a non-lambda plus an extra argument gives B007 and B004 (B);
    - B008 together with Q006/Q007 (C).
- **A loop's integer start.** C and D: the kit requires an integer loop start (L007), and the sheet's wording allows `0.5`. This is a sheet wording point.
- **`units` lists only bindings a lambda reads**, so an unused `const S = "x"` passes (E, F). The sheet's rule concerns constants a lambda reads, so F judged this fine.
- **E's miss is a reading miss, not a documentation gap.** E tested `if (p.vel)`, which the kit refuses anyway, and not `if (p.heat)`. It never turned on `conditions: "bool"`, though five agents found it.

## Verdicts

**H5: Pilot, six agents, two each of Opus, Sonnet and Haiku, on particles built through the API from START.md and API.md alone (7,994 tokens).**
- **Built:** every agent built a passing language. Measured from their transcripts, none read kit source and none hand-wrote a builder.
- **Score:** over the scored hidden set (27 accepts, 141 rejects), four were perfect, beating the reference. The other two missed only rules the reference also misses, plus, for E, one option it never turned on.
- **Strictness:** H5 now holds for the rules the kit can say. It still does not hold for the sheet's full strictness. Three of six agents wrote a parser of 320–560 lines for the rules Ben parked and for the uncalled helper's parameter type.
- **What this comes to:** the documents are sufficient. The remaining gap is the kit's design, not the documents.

**H11: Not tested in M3.** No agent wrote a pass.
