## Do first

   - automatic semicolon insertion and other places where the parser accepts input JavaScript would reject;
   - spans that don't slice back to their source;
   - fixits whose output changes meaning, such as template literals with `"` or `\` in their text, or `==` found inside a string or comment;
   - tests that pass for the wrong reason.

   Note that two mutations (precedence, semicolon insertion) were each caught by a test.
2. **Then dispatch `KHQFvD` → `1ev20M` to one agent, in order**, as the plan intends. Read `project/agents/delegation.md` first. The leaves carry the rulings, but restate these in the brief:

   - Ask Ben before widening the subset beyond the rulings.
   - The DMG `draw` and `hud` lambdas run in `render()`, so their effects show only in the framebuffer hash.
