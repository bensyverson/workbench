# Draw-list paper trial

The dogfood trial of the ruled draw-list draft ([project/2026-11-26-draw-list-draft.md](../../project/2026-11-26-draw-list-draft.md), "Next"), before `Draw` is built (leaf `e3qYus`). A relay of three blind sessions: a **maze author** gives the maze package (entity-shaped) a `Draw` output built one op per item; a **particles author** gives particles (Canvas-shaped) one built with a pen; a **composer**, on their hand-ins, writes a **root package** whose `Draw` inputs take both pictures and whose `Draw` output layers them with a HUD, and a glue program that wires and shows it. The findings are in [project/2026-11-26-draw-list-trial-findings.md](../../project/2026-11-26-draw-list-trial-findings.md).

It is a **paper trial**: `Draw` does not exist in the kit, so the checker emulates it from the packet's `draw.md`, on the real kit for everything else. It reuses the seams relay harness ([scripts/seams-trial/](../seams-trial/README.md)): its run.sh guards, its placeholder `seams.md`, `runtime.md` and `packaging.md`, its package checks and G codes, its loader, D-pad and run helpers, and its `summary.js`.

## Running the trial

The maze and particles legs run in parallel, then the compose leg on their hand-ins:

```sh
scripts/draw-trial/run.sh maze /private/tmp/e3qYus-maze claude-sonnet-5-5
scripts/draw-trial/run.sh particles /private/tmp/e3qYus-particles claude-sonnet-5-5
scripts/draw-trial/run.sh compose /private/tmp/e3qYus-compose claude-sonnet-5-5 /private/tmp/e3qYus-maze /private/tmp/e3qYus-particles
node scripts/seams-trial/summary.js /private/tmp/e3qYus-maze /private/tmp/e3qYus-particles /private/tmp/e3qYus-compose
```

`run.sh` needs the sandbox off (`claude` reads `~/.claude`).

**Run 2026-11-26** (one relay, Sonnet 5.5 at every leg). The maze leg took 9 turns, 82 s and $0.34, and was clean at run 1. The particles leg took 9 turns, 62 s and $0.34, and was clean at run 1. The compose leg took 12 turns, 125 s and $0.56, and failed W024 three times. That was a checker defect: W024 converted the coin's cell by the maze's Draw wire edge, which starts from the frame the picture is drawn in. It is now fixed, with the recorded leg as its regression test. The composer's hand-in, unchanged, now checks clean, with a burst of 60 ops over the coin at (44, 68). The author legs' Game Boy note also now says that it fits the frame to the screen, which the maze leg had read as contradicting `draw.md`. The findings are linked above. Copy each leg to `runs/<date>/<leg>/` afterwards, and `diff -r` the composer's `maze/` and `particles/` against the authors' hand-ins (the checker trusts the hashes).

> **2026-11-26, after the run:** ruling 6 made an Event record global optional, so the recorded compose leg (`runs/2026-11-26/compose`), the reference hand-ins and their particles `examples/07.js` now guard `ev` with `if (ev != null)`, and the particles packages were rehashed. That one-line guard is the only change to the recorded hand-in; it keeps the W024 regression test running.

## The legs on the real kit (leaf `GCy994`, 2026-11-26)

The Draw build ([kit/draw](../../kit/draw/README.md)) replaces the checker's emulation for the acceptance run. `massaged/2026-11-26-compose/` is the recorded compose leg's hand-in (its `maze/`, `particles/`, `arcade/` and `workbench.js`, which hold the two author legs' hand-ins unchanged), massaged to the rulings of 2026-11-26 (leaf `pSo5YA`), each manifest rehashed with `node scripts/pkg/hash.js <package>`. `test/accept.test.js` loads it with the seams relay's loader on the real kit (no Draw stand-in), checks and builds it, steers the maze onto a coin, and checks that the shown list holds the burst's ellipses over the maze with the HUD on top, that it draws on Canvas, and that the Game Boy profile refuses it by kind at composition (S401: `rect` from the root and the maze, `ellipse` from the maze and the particles) and at draw time (J042). These packages draw with rects and ellipses, so no leg fits the Game Boy; kit/draw's tests hold a Game Boy-shaped list that does.

**The massage, against `runs/2026-11-26/compose`** (`diff -r runs/2026-11-26/compose massaged/2026-11-26-compose`, ignoring the records and the three rehashed manifests): four source files.
- **arcade** (ruling 4): the view's builder reads the record and the inputs global, `(s, record) => [ … ...wired.board, ...wired.effects, … "SCORE " + wired.score … ]`, instead of a second parameter of Draw inputs and a state that mirrored them. Its state shrank from five fields to `{ t }`, its runtime from a copy of the inputs to a clock (6 changed lines in the Dialect, 4 in the runtime, 1 in its text view).
- **maze** (ruling 1): one added line, `max: (record) => 1 + record.grid.length * record.grid[0].length`, so its list's max follows the built grid under the `Draw<1025>` ceiling.
- **particles** (ruling 1): one added line, `max: (record) => record.maxParticles`.

The glue is unchanged. Builders, layers, colors and the op fields the packet chose needed no change, which is the finding: the rulings changed what a root writes, not what an author leg wrote.

**Lowering the builders (leaf `vcIzt1`, 2026-11-26)** forced a second massage, of three Dialect files and one runtime (each manifest rehashed): every change is a builder reading something that was a JavaScript closure, or a string's length.
- **maze:** the floor layer read `s.grid[0].length`, which lowering refuses twice (a list index may be empty, L008; a string has no `length`, L002). The state gains `size: struct({ cols, rows })`, set once by the runtime's init (1 line), and the floor reads `s.size.cols` and `s.size.rows` (1 line). The builders read `CELL`, a top-level const of the file (L001), now also the Library constant `library: { CELL: { const: String(CELL) } }` (1 line). 3 lines in the Dialect and 1 in the runtime.
- **particles:** the pen called `tint` and `radius`, top-level helpers of the file (L001); they are now also Library functions, `library: { tint: { fn: String(tint) }, radius: { fn: String(radius) } }` (1 line).
- **arcade:** the view read `LINE`, a top-level const (L001), now `library: { LINE: { const: String(LINE) } }` (1 line).

Nothing in a builder's own text changed but the maze floor's one line: the op literals, the ternaries over two op kinds, the concatenation of two Draw inputs with a HUD, and the pen's `for…of` all lowered as written.
