# DMG differential run and lowering survey

M1's report numbers, reproducible. Two verbs over the [lowering pipeline](../dmg-lower/README.md) and the [oracle](../dmg-oracle/README.md):

```sh
node scripts/dmg-diff/cli.js survey            # lower all 22 presets; per-preset counts, then every rejection with its diagnostics
node scripts/dmg-diff/cli.js diff              # cases over presets 04-07, seeds 7, 11, 23, 3000 frames each
node scripts/dmg-diff/cli.js diff --case "04 sweep" --seeds 7 --frames 600
node scripts/dmg-diff/cli.js diff --all-presets --seeds 7,11 --frames 1200   # one default case per preset with runtime lambdas (about 29 s)
node scripts/dmg-diff/cli.js mutants           # planted faults in emitted lambdas, through every case of their preset
```

`--json` gives any verb's full result, with the same exit code as the text form. `diff` exits 1 when any trace differs **or any run's original stopped short of its frames**; `mutants` exits 1 when a mutant not marked equivalent is missed, or when one marked equivalent is caught (printed "caught (marked equivalent: claim is wrong)"); both exit 2 on bad usage.

- **Mutants** ([`sensitivity.js`](sensitivity.js), `MUTANTS`): textual faults in emitted lambdas, taken from the IR review's probe. A mutant no run can tell apart carries the reason it is equivalent under the host; any other miss is a gap in the cases. The probe plants a fault through the same emit-and-transform path as `runCase` (`plant`, `emitGroup`).

- **Survey classes** ([`survey.js`](survey.js)). A rejected lambda is `helpers` when it uses a top-level binding of its preset (the inventory's `topLevelRefs`), whatever else is wrong with it; else `not-yet` when every error is a gap in lowering or the DMG dialect: L012; L002 only when the member exists on the host (a key of the world object the runtime hands lambdas, plus `world`, or a String or Array member; the diagnostic's source text names it, so `self.tll` is a typo and `subset`); L015 only for `reduce got …` (arity on `filter`, `find`, `some`, `every` is the program's); else `subset`. `classify` is pure: the host's members arrive as a `hostHas(name)` predicate built by `hostMembers(dmg)`. A fragment lambda counts once, and lowers only if it lowers for every part that runs it. Known blind spot: lowering does not look inside a `for…of` body, so an error there is hidden (job m82n5e).
- **Differential cases** ([`differential.js`](differential.js), `CASES`). Each names a preset, live params, build-time overrides, or a textual edit of the preset's source, and says what it exercises. `04 linger 0 (edited)` is a test program derived from preset 04, not the preset: it makes the u16 wrap reachable. For each case and seed, every lowerable lambda is swapped for its emitted JS alone, then all at once, and each run's trace (state, log, RNG draws, framebuffer every 4th tick) is compared with the original's. The output also reports what the original run reached: ticks run, ticks spent game over, host wrap warnings (deduplicated per attribute by the host), RNG draws.
- **Early stops and distinct runs.** A `DiffResult` carries `ticks` (ticks the original ran) and `error` (its runtime error, or null). An original that stops short of `frames` is a failure: the CLI prints `STOPPED after N of F frames: <error>` and exits 1, since a match over a truncated run proves little. `fingerprint` hashes the original trace (the host's "seed N" log label blanked), and the summary reads "30 runs (24 distinct), 0 with a difference": 04 sweep, 05 default and 05 linger 2.5 are seed-independent, so their seeds replay one trace.
- **The swap is guarded.** `runCase` takes an optional `transform(slot, source)` applied to each emitted source before it is instantiated; the fast suite plants a `MUTANTS` fault through it and expects mismatches for the slot and for `*`, which fails if a swap goes into a build nobody runs. `swapLambda` replaces one function per slot, so a fragment lambda whose parts emit different code makes `emitGroup` throw naming the slot; no preset has one today.
- **`--all-presets`.** One default case per preset that has runtime lambdas (21; 02 has none), honoring `--seeds` and `--frames`; the summary adds the swapped-lambda total, which equals the survey's lowered count (111 since array literals record their length).
- **Tests.** `test/dmg-diff.test.js` pins the survey's figures, the classifier, the guards and the CLI's exit codes, and runs short cases (fast suite). `prerelease/diff.prerelease.js` runs every case on three seeds for 3000 frames, then every preset's default on seeds 7 and 11 for 1200 frames against the survey's lowered count (`npm run test:prerelease`).
