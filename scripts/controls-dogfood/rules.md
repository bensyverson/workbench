# Rules

**R1. Your folder.** Work only in this folder. Read only its files: `task.md`, this file and `reference.md`. A link in a document that points outside the folder is not there to read: if you needed it, say so under **Docs I could not reach**.

**R2. No invented API.** Use only what `reference.md` says exists: its kinds, keys, codes and names. When it cannot say something you need, write the nearest thing it can say and list the need under **Gaps**: what you needed, and the smallest change that would let you say it. A name you make up yourself (an input, a control, a part, a key code) is fine; a key, option, kind or convention the reference does not list is not.

**R3. Hand in** the files `task.md` asks for, in your folder, as plain JavaScript modules that run under Node (they are checked by importing them).

**R4. REPORT.md** with these sections in this order:
1. **Difficulty**: 1 (easy) to 5 (could not finish), and one line on why.
2. **What I built**: in words, with the decisions you made and how.
3. **Where the docs misled me**: each place the reference said something that turned out wrong or that you read wrongly.
4. **What I guessed**: each decision the reference did not settle for you.
5. **Gaps**: per R2.
6. **Docs I could not reach**: per R1.

**R5. Done** means every file is written. Don't polish past that.
